Gacha life cycle

In Construction

This is the first state of a gacha.

In this state, the owner must import and name at leat 4 items in a deadline of 1 week (to avoid dead items).

The owner specifies the gacha title, description, and the price () to pull an item.

The owner can modify or delete the gacha only while it's in construction.

When the owner finished constructing their gacha, they can publish it and the gacha becomes active.

Active

When a gacha is active, a copy of each item and each effect is available.

In this state, anyone (except the owner) can pull an item for the price () specified by the owner. The points go directly to the owner.

When there is no more items to pull, the gacha turns into the empty state.

Empty

The gacha only displays the items that were available in it.
